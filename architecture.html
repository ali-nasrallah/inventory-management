System Documentation

Factory Inventory Management — Architecture

A full-stack demo application for tracking inventory, orders, demand forecasts, backlog, and spending across factory warehouses. Vue 3 single-page client backed by a FastAPI service over in-memory JSON data.

System Architecture

Client :3000
  • Vue 3 SPA Composition API, served by Vite
  • vue-router 7 routes: Dashboard, Inventory, Orders, Spending, Demand, Reports, Backlog
  • Composables useFilters, useAuth, useI18n (en / ja)
  • axios centralized in src/api.js
API :8001
  • FastAPI REST endpoints under /api/*
  • Pydantic models InventoryItem, Order, DemandForecast, BacklogItem, PurchaseOrder
  • Filter helpers apply_filters(), filter_by_month() incl. Q1-Q4 mapping
  • CORS open demo only — allow_origins=["*"]
Data in-memory
  • mock_data.py loads JSON at startup, mutates in process
  • 7 JSON files inventory, orders, demand_forecasts, backlog_items, purchase_orders, spending, transactions
  • No database restart reloads the seed data

Request & Data Flow

1
User interaction
client/src/views/*.vue

A view (e.g. Dashboard.vue) renders. The shared FilterBar updates refs in useFilters — selected warehouse, category, status, time period.

2
API client builds the request
client/src/api.js

The view calls api.getX(filters). URLSearchParams are appended only when the filter is not 'all', keeping URLs clean.

3
HTTP to FastAPI
GET http://localhost:8001/api/...

axios sends the request. CORS middleware on the server accepts all origins for development.

4
Server filters in memory
server/main.py — apply_filters(), filter_by_month()

Endpoint handler reads the matching list from mock_data, applies warehouse/category/status filters, then maps month or quarter (Q1-2025 → Jan/Feb/Mar) against order_date.

5
Pydantic validation
response_model=List[Model]

The response is shaped through a Pydantic model so the contract with the client is explicit and typed.

6
Reactive render
refs → computed → <template>

The view stores raw data in ref(); derived values (totals, low-stock counts, chart series) live in computed(). Vue re-renders only the affected nodes.
